 Sobre o projeto

Este projeto consiste em um **portfólio pessoal desenvolvido para apresentar minha trajetória, conhecimentos, habilidades e projetos na área de Tecnologia da Informação**.

O objetivo do portfólio é reunir informações profissionais e acadêmicas em uma interface moderna, organizada e responsiva, facilitando a apresentação do meu perfil para oportunidades de estágio, trabalho e conexões na área de tecnologia.

 Funcionalidades

* Página inicial de apresentação
* Menu de navegação entre as seções
* Layout responsivo
* Seção "Sobre mim"
* Apresentação da formação acadêmica
* Exibição das principais habilidades técnicas
* Área dedicada aos projetos
* Links para contato e redes profissionais
* Menu responsivo para dispositivos móveis
